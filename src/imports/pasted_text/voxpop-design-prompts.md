# voxpop — Figma 디자인 프롬프트 (terminal / ASCII-vibe 버전)

> **쓰는 법**: Figma Make(`figma.com/make`) 또는 Figma의 AI 디자인에 STEP 0(디자인 시스템)을 먼저 넣고, 이어서 STEP 1~4를 페이지별로 넣는다. 한 번에 다 넣어도 되지만 나눠 넣으면 페이지마다 품질이 더 좋다.
>
> 바이브 레퍼런스 = Hermes Agent(hermes-agent.nousresearch.com) — 모노톤·터미널·그리드 보더·세리프/모노. voxpop은 색만 그린으로.

---

## STEP 0 — 디자인 시스템 (먼저 넣기)

```
voxpop이라는 한국 스타트업 웹사이트를 만들 거야. 터미널/CLI/오픈소스 개발자 감성의, 모노톤이고 깔끔하고 힙한 사이트. 레퍼런스 바이브는 Hermes Agent 사이트(모노톤 단색 + 터미널 창 + 얇은 보더 그리드 + 모노스페이스). 모든 UI 텍스트는 한국어.

# 제품
voxpop = 동네 카페·식당 사장님을 위한 '익명 손님 피드백 → AI 오늘의 액션' 서비스.
손님이 매장 QR을 찍고 익명으로 별점·한마디를 남기면, AI가 욕설·개인정보를 자동으로 가리고, 사장님은 "가려진 솔직한 한마디 + 오늘 할 일"을 받는다. 손님 한마디가 쌓일수록 '매장 나무'가 자란다.

# 톤·무드
터미널/개발자 인디 감성 + 진지함. 과하게 귀엽지 않게, 깔끔하고 똑똑해 보이게. 모노톤 그린.

# 디자인 시스템 (토큰/변수로 만들고 전 화면 일관 적용)
색 (그린 모노톤, 순백·그라디언트 금지):
- 배경 옅은 세이지 #E7EEE3 / 카드·터미널 면 #F2F7EF / 한 단계 면 #EDF3E9
- 잉크(본문) #12301D / 보조 텍스트 #516658
- 보더(얇은 선) #B2C8AB / 더 옅은 보더 #CFDEC9
- 액센트 그린 #1B6B42 / 밝은 그린 #3E8E63
폰트:
- 영문·숫자·코드·라벨·메뉴·메타 = 모노스페이스(JetBrains Mono)
- 한글 본문·헤드라인 = Pretendard. 헤드라인은 아주 굵게(800), 본문 15~16px.
레이아웃·디테일:
- 전체를 얇은 1px 보더로 나눈 '그리드 셀'로 구성 (네비·피처·푸터가 셀로 쪼개짐)
- 상단에 status 바: "● voxpop daemon — running · 무기명 · 자동 가림 · 공개 리뷰 아님"
- 터미널 창 컴포넌트: 좌상단 점 3개(● ● ●) + 타이틀 + 안에 명령 로그(`$ 명령`, `→ 진행`, `[##########]`, `›` 불릿). 깜빡이는 커서(█).
- 모노 라벨 장치: [ 01 ] · $ · // · › · ── 구분선 · [ copy ]
- 종이 위 2~5% 미세 그레인/노이즈(빈티지 질감). 강한 그림자 대신 보더 + 살짝 offset 그림자(터미널 창만).
- 모션은 절제: 커서 깜빡임, 터미널 로그 한 줄씩 타이핑되는 느낌, hover 시 셀 배경 미세 변화.

# 마스코트는 ASCII '바이브'지 순수 텍스트가 아님 → 픽셀아트/도트(8-bit) 일러스트로 그린다. 모노톤 그린, 레트로 터미널 감성.
(아래 STEP들에서 상세)

순수 텍스트 아트 말고, 깔끔한 도트/픽셀 일러스트로. 진지하고 똑똑하고 힙하게 만들어줘.
```

## STEP 1 — 매장 나무 성장 시스템 (마스코트, 5단계)

```
voxpop의 매장 마스코트는 '나무'다. 사장님 매장 = 나무이고, 손님 한마디가 쌓일수록 자란다. 픽셀아트/도트(8-bit) 스타일, 모노톤 그린(#1B6B42 계열 명암), 터미널 감성. 순수 ASCII 텍스트 아님.

성장 5단계를 각각 디자인해줘 (가로로 나란히, 단계별 LV 배지 + 진행 바):
- LV.1 새싹     : 흙(점선 베이스)에서 막 돋은 떡잎 2장. 아주 작게.
- LV.2 어린싹   : 가는 줄기 + 잎 3~4장.
- LV.3 묘목     : 작은 나무 형태, 가지가 갈라지기 시작.
- LV.4 나무     : 제대로 자란 나무, 풍성한 잎, 튼튼한 줄기.
- LV.5 금전수(최종 진화) : 울창하고 큰 나무 + 가지마다 돈다발·금화가 주렁주렁 매달림. 사업 번창의 상징. 살짝 반짝이는 디테일(✦ 같은 점). 가장 화려하게.

각 단계 아래에 모노 라벨: "LV.N · 한마디 N개" + 진행 바 [████░░░░] 스타일.
사장님 화면에선 나무가 '건강'도 표현: 미조치가 쌓이면 잎이 살짝 시들거나 색이 옅어짐(단, 절대 죽지 않음 — 시듦까지만).
픽셀 도트로 깔끔하고 귀엽되 유치하지 않게, 터미널 그린 톤으로.
```

## STEP 2 — 손님 고양이 + 꾸미기(코스튬) 시스템

```
voxpop의 손님 마스코트는 '고양이'다. 손님은 QR 찍고 익명 고양이가 되어 한마디를 남긴다. 픽셀아트/도트(8-bit), 모노톤 그린, 터미널 감성.

고양이 + 꾸미기(코스튬) 시스템을 디자인해줘:
- 기본 고양이(픽셀 도트) + 표정 변형 3종(기본 / 졸린 / 기쁜).
- 한마디를 남길 때마다 생선 토큰 '><>'(ASCII 물고기 표기)을 적립.
- 생선으로 코스튬 해금: 리본 · 베레모 · 턱시도 · 왕관 등. 고양이에 씌운 모습 각각.
- 옷장(closet) UI를 '터미널 인벤토리' 스타일로:
  CLOSET ── 내 옷장                    >＜> x 12
  [x] 기본 고양이                        보유
  [x] 리본                              보유
  [ ] 턱시도                            >＜> 8
  [ ] 왕관 고양이                        >＜> 20 · 잠김
  › 한마디 남길 때마다 >＜> +1 — 다음 해금까지 N마리
- 무기명 원칙: 코스튬은 손님 기기에만 저장, 어느 가게를 다니는지 가게엔 안 알려짐.
유치하지 않게, 픽셀 도트로 깔끔하고 힙하게.
```

## STEP 3 — 랜딩 페이지 (사장님 설득)

```
같은 voxpop 디자인 시스템(그린 모노톤 + 터미널 + 보더 그리드 + 모노 폰트 + 픽셀 나무/고양이)으로 랜딩 페이지. 위에서 아래로:

1. status 바: "● voxpop daemon — running · 무기명 · 자동 가림 · 공개 리뷰 아님"
2. 네비(보더 그리드 4셀): 로고 voxpop(모노) + 소개 / 작동 방식 / 시작하기 →
3. 히어로(2단 그리드):
   - 좌: 모노 라벨 "OPEN FEEDBACK · 사장님만 보는 비공개 채널" + 빅 헤드라인 "손님의 한마디로,\n가게가 자랍니다." + 서브 카피 + 터미널 설치 박스(`$ voxpop store add "우리 카페"` / `$ voxpop qr --print` + [copy])
   - 우: 픽셀 매장 나무(LV.4) + 진행 바 [████████░░] LV.4 + "매장 나무 · 한마디 +6 → 한 뼘 자람"
4. 터미널 데모 섹션 "$ SEE IT IN ACTION": 터미널 창 안에서 `voxpop today` 실행 → "오늘 할 일"(화장실 청결 점검·대기 안내 개선) + 주간 신호 막대(맛 ████████░░ 등) + "▲ 매장 나무가 한 뼘 자랐어요" 로그.
5. 피처 3그리드(보더 셀): [01] 무기명(누가 썼는지 영원히 모름) / [02] 자동 가림(위험한 말은 가리고 신호는 살림) / [03] 오늘 할 일(한마디를 한 줄 액션으로). 각 셀 하단에 모노 메타(device=null·ip=hashed 등).
6. 나무 성장 5단계 띠: 새싹→…→금전수(돈다발) 가로 나열 + "한마디가 쌓일수록".
7. 손님 고양이 꾸미기 섹션 "$ voxpop cat --closet": 고양이 + closet 인벤토리.
8. 푸터(보더 그리드): voxpop v0.1.0 — beta · EST 2026 · ANONYMOUS BY DESIGN.

진지한 카피 + 터미널/개발자 감성. 데스크톱+모바일 반응형.
```

## STEP 4 — 손님 폼 / 스레드 / 사장 대시보드

```
같은 voxpop 디자인 시스템으로 나머지 3화면.

(A) 손님 폼 (모바일, QR 진입):
픽셀 고양이가 위에서 인사 → "오늘 어떠셨어요?" 별점(터미널st, 탭하면 채워짐) → (1~3점) 아쉬운 점 칩 → 한마디(선택) → 제출. 완료 화면: 고양이가 기뻐하며 생선 ><> +1 적립 애니메이션 + "읽고 진짜 바뀝니다. 영수증 링크로 사장님 답 보기". 상단에 "이름·번호 안 받아요 · 욕설·개인정보 자동 가림" 신뢰 라벨.

(B) 손님 스레드 (내 한마디 + 사장님 답):
터미널 대화 로그 스타일. 내 한마디(고양이 + 가림 안내) → 사장님 답(매장 나무 + 답). 세로 흐름. "이 대화는 영수증 링크로만, 사장님은 누가 썼는지 끝까지 몰라요" 무기명 안내. "한마디 더 남기기".

(C) 사장 대시보드 (데스크톱+모바일):
터미널 today 창(voxpop today 로그) + 매장 나무(LV·건강 상태) 패널 + "오늘 할 일" 영웅 카드 + 주간 신호 막대 + 한마디 카드 리스트(메타·가림 본문·처리상태 토글·답하기). 긴급(안전·위생)만 강조색, 나머지는 모노톤. 낙관적 UI(즉시 반영).

전부 그린 모노톤 + 터미널 + 픽셀 마스코트.
```

## 절대 지켜야 할 것 (모든 STEP 공통)
- 무기명: 손님 신원·기기·위치·원본 텍스트 어떤 화면에도 0. 사장은 누가 썼는지 영원히 모름. 시간은 상대값.
- 가림: 사장이 보는 본문은 항상 가려진 버전. "욕설·개인정보 자동 가림"을 신뢰 신호로.
- 나무 건강: 사장 화면만 건강 표현(시듦까지, 죽음 없음). 손님에겐 성장(긍정)만.
- 정직: "매출 2배" 같은 과장 금지. 순백 배경·그라디언트 메시·뉴모피즘 금지.

## 카피 톤 (진지하게 — 개인 일화 금지)
헤드라인 "손님의 한마디로, 가게가 자랍니다." / 문제 섹션은 구조적 실태 + 검증 수치로:
"부정 리뷰는 업주 요청만으로 내용 검증 없이 가려집니다(배민 최대 30일 블라인드). 후기 작성자의 65.2%는 보상 이벤트 때문에 썼고, 그 98.3%가 실제보다 높게 평가했습니다(한국소비자원 2024)." — 창업자 짬뽕 일화 같은 개인사는 넣지 않는다.
```
